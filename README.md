# 🏏 Cricket Player Performance Prediction System

An AI-powered web application that predicts **runs and wickets** of IPL players using historical match data and machine learning models.

---

## 📌 Project Overview

This project analyzes IPL (2008–2024) ball-by-ball data to:
- Predict a player's **batting and bowling performance**
- Visualize recent form and trends
- Explain predictions using **SHAP**
- Provide an interactive **Streamlit dashboard**

---

## 🚀 Features

- Role-based predictions (Batsman / Bowler / All-Rounder)
- Runs & wickets prediction for next match
- Batting & bowling form trends (last 5 matches)
- Bowling economy analysis
- SHAP explainability for model transparency
- Combined performance radar chart
- Match context and opponent selection

---

## 🧠 Machine Learning Models

- **Runs Prediction:** XGBoost Regressor  
- **Wickets Prediction:** XGBoost Regressor  
- Feature preprocessing using Scikit-learn Pipelines  
- Model explainability using SHAP
